AI-тесты используют имитацию ответов провайдера; результаты команды с реальным API сохранены в [отчёте приёмки](docs/DOD-RESULTS.json). Модель не определяет состав и порядок выдачи, ключ используется на сервере. Доступность выбранных моделей на другом аккаунте нужно проверить отдельно.

## 5. Черновик, календарь, голос и избранное — подключены к интерфейсу

- [x] Добавить `/api/calendar`: доступность, количество анкет в бюджете и минимальная начальная цена по всем 100 дням учебного календаря.
- [x] Добавить `/api/transcribe` и `OPENAI_MODEL_TRANSCRIBE`: проверка формата и размера, расшифровка без сохранения и кеша аудио.

- [x] Подключить разговорный интерфейс к черновику и обновлять результаты только после подтверждения пользователем.

- [x] Добавить общее окно избранного для обоих режимов, валидацию сохранённых данных и сохранение после перезагрузки браузера.

Локально в браузере без ключа проверены поиск готового запроса с карточками в чате, независимость ручного поиска и общее окно избранного. Смена даты через календарь и избранное после перезагрузки проверены на предыдущем этапе интерфейса. Физический микрофон пользователя при проверках команды не записывался. Стоимость аудио пока возвращается как неизвестная.

Измеренное время и стоимость относятся к конкретному прогону.
