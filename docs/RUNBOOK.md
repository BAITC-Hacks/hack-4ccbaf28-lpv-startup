# Запуск и демонстрация LPV Match

Проверено 23.09.2026: `npm test` — 22 теста, типы, форматирование и production-сборка проходят. В новом интерфейсе команда измерила реальный AI-поиск: 2,82 с; отдельно синтетическая запись длиной 7,47 с расшифрована за 2,93 с. Это отдельные измерения, а не гарантия скорости каждого запроса. Детали и границы проверки — в [VOICE-AND-BRIEF.md](VOICE-AND-BRIEF.md).

Разговорный интерфейс, календарь, голос и избранное подключены. Новая заявка пустая; примеры и ответы ассистента заполняют черновик, а поиск запускается только после подтверждения. В браузере без ключа проверены этот переход, смена даты через календарь и сохранение избранного после перезагрузки.

## Быстрый запуск

Требуется Node.js 22+ и npm. Разработка проверена на Node.js 26.7.0.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Открыть http://127.0.0.1:3000. Без ключа доступны «Параметры», примеры, календарь, строгий поиск, локальные объяснения и избранное; AI-чат и запись голоса отключены. Для разбора текста, голоса и AI-выбора цитат добавьте **свой** `OPENAI_API_KEY` в `.env.local` и перезапустите сервер. Ключ команды не поставляется и не нужен для независимого запуска локального режима.

Две модели настраиваются в `.env.local`:

```dotenv
OPENAI_MODEL_FAST=gpt-5.4-nano
OPENAI_MODEL_REASONING=gpt-5.4-mini
```

Для расшифровки отдельно настраивается `OPENAI_MODEL_TRANSCRIBE=gpt-4o-mini-transcribe`. Нужен тот же собственный `OPENAI_API_KEY`. Команда проверила реальную транскрипцию синтетического аудио; перед демонстрацией отдельно проверьте физический микрофон и разрешение браузера на своём устройстве.

Текстовые модели должны поддерживать Responses API, function calling, Structured Outputs и `reasoning.effort: none`. Для неизвестных тарифов стоимость показывается как неизвестная; стоимость аудио пока не вычисляется. NVIDIA в текущий MVP не подключена; GPU не используется.

Для запуска готовой сборки остановить dev-сервер (Ctrl+C), затем:

```sh
npm run build
npm start
```

Порт можно изменить: `npm run dev -- --port 3001`. Сервер слушает только `127.0.0.1`.

## Проверки

```sh
npm test
npm run typecheck
npm run format:check
npm run build
```

Тесты не требуют ключа и не обращаются к внешнему API: интеграционные отказы/ответы провайдера имитируются. Проверяются все ограничения, границы бюджета/часов, 6600 запросов по официальному календарю, повторяемость порядка, альтернативы, несуществующие AI-цитаты, кеш и отказ API. Реальные API-вызовы дополнительно проверены вручную.

Повторный импорт исходника: `npm run data:import`. JSON уже включён в репозиторий, импорт для запуска не требуется.

## Сценарий демонстрации (3–4 минуты)

1. **Массовая категория.** Нажать «Ведущий на корпоратив»: пример заполняет заявку, но не выполняет поиск. Проверить Алматы, 15.10.2026, корпоратив, до 1 000 000 ₸, русский, 6 ч и пожелания. Нажать «Подобрать варианты». Ожидаются Мицури Канроджи (`HK-44923`), Буллма (`HK-44733`), Хаул (`HK-77838`). Открыть «Почему подходит и анкета».
2. **Календарь и занятость.** Нажать «Сравнить даты», выбрать 17.10.2026 и подтвердить подбор. Мицури занят и исключён; первые три: Буллма, Хаул, Кики (`HK-35215`). Цены в календаре — минимальные начальные цены доступных анкет, не скидки.
3. **Редкая категория.** «Новый подбор» → «Камерная флористика» → «Подобрать варианты». Одна анкета: Тони Тони Чоппер (`HK-39372`). Интерфейс показывает реальное количество результатов.
4. **Пустая выдача.** «Новый подбор» → «Проверить ограничения» → подтвердить. Бюджет 100 000 ₸ не проходит. Альтернатива 650 000 ₸ даёт одну анкету при остальных прежних условиях; нажатие «Применить и подобрать заново» явно запускает поиск.
5. **Нет категории.** В примере флористики открыть «Параметры», выбрать «Зарубежье» и нажать «Подтвердить и подобрать». Получится отдельное состояние отсутствия категории.
6. **Избранное.** Нажать сердечко на карточке, перезагрузить страницу и открыть «Избранное». Анкета и условия сохранённого запроса остаются; это отметка в браузере, не бронь.
7. **Агент и экономика — со своим ключом.** Ввести: «Нужен ведущий в Алматы на корпоратив 15 октября, бюджет миллион тенге, русский язык, 6 часов. Спокойно, интеллигентно, с юмором». Проверить заполненную заявку, подтвердить подбор и открыть «Модели и расход API»: заполнение черновика → фильтры → объяснения с проверенными цитатами. Повтор неизменного запроса использует кеш.
8. **Голос — после проверки микрофона.** Первое нажатие кнопки записи включает микрофон, второе завершает и отправляет аудио. Есть отмена и лимит 60 секунд. После расшифровки проверить черновик и отдельно подтвердить поиск. Автоматического перехода к результатам при обработке голоса нет; переход по уведомлению выполняет пользователь.

## Ограничения и честное описание AI

- Это подбор по учебному каталогу, без бронирования и подтверждения реальной доступности.
- Даты доступны только с 23.09 по 31.12.2026; цены начальные. Все метки происхождения сохранены.
- Ранжирование детерминированное, на основе явных лексических признаков стиля и запаса бюджета; эмбеддинги и дообучение не используются.
- Модель выбирает индивидуальные основания и точную цитату. Текст собирается из проверенных фактов; свободную генерацию неподтверждённых сведений не показываем. Недействительная цитата заменяется локальным объяснением.
- До трёх кандидатов передаются объясняющей модели; весь каталог и календарь не отправляются.
- При неработающем API форма и поиск продолжают работать. Ошибка разбора свободного текста явно сообщается, параметры молча не подменяются.
- Кеш — в памяти одного процесса, 30 минут, до 150 ответов. После перезапуска исчезает. Расход в панели относится к текущей вкладке, не ко всему аккаунту.
- Лимит: 30 запросов в минуту на локальный процесс. Нет регистрации, БД и обязательных внешних сервисов для поиска по форме.
- Избранное хранится только в этом браузере. Доступность карточки относится к сохранённой дате; для актуального подбора выполните поиск повторно.
- Аудио отправляется в OpenAI; приложение не сохраняет его на диск и не кеширует. Максимум — 8 МБ; стоимость аудио пока неизвестна.
- Иллюстрации созданы AI и не являются фотографиями подрядчиков, портфолио или основанием ранжирования. Источник: [VISUALS.md](VISUALS.md).
