# Запуск и демонстрация LPV Match

Проверено 23.09.2026: 28 тестов, TypeScript и production-сборка проходят. Шесть сценариев Definition of Done прошли с реальным API: максимум 3,541 с, повтор из кеша — 12 мс. Полный сценарий живой защиты и точный отчёт: [DEFINITION-OF-DONE.md](DEFINITION-OF-DONE.md), [DOD-RESULTS.json](DOD-RESULTS.json).

Решение — AI-режим для существующего агрегатора: единый чат с карточками в ответах, отдельный ручной режим с фильтрами и результатами под ними, голос, календарь и общее локальное избранное. Интеграцию с боевым агрегатором не заявляем. Независимый контракт движка: [ENGINE-API.md](ENGINE-API.md).

Разговорный интерфейс, календарь, голос и избранное подключены. Новая заявка пустая; ответы ассистента заполняют черновик, а поиск запускается после подтверждения. Стартовые готовые запросы показывают дату, город и бюджет; нажатие сразу запускает поиск по этим условиям. В готовых запросах явно указано 15 октября 2026. Слово «сегодня» в примерах не используется; относительные даты в свободном тексте вычисляются по реальной дате Asia/Almaty. В браузере без ключа проверены этот переход, смена даты через календарь и сохранение избранного после перезагрузки.

Это отдельные измерения, а не гарантия скорости каждого запроса. Детали голосового этапа — в [VOICE-AND-BRIEF.md](VOICE-AND-BRIEF.md).

## Быстрый запуск

Требуется Node.js 22+ и npm. Разработка проверена на Node.js 26.7.0.

```sh
npm ci
cp -n .env.example .env.local
npm run dev
```

Открыть http://127.0.0.1:3000. Без ключа доступны «Ручной режим», примеры, календарь, строгий поиск, локальные объяснения и избранное; AI-чат и запись голоса отключены. Для разбора текста, голоса и AI-выбора цитат добавьте **свой** `OPENAI_API_KEY` в `.env.local` и перезапустите сервер. Ключ команды не поставляется и не нужен для независимого запуска локального режима.

Три задачи распределены между моделями. Текстовые модели настраиваются в `.env.local`:

```dotenv
OPENAI_MODEL_FAST=gpt-5.4-nano
OPENAI_MODEL_REASONING=gpt-5.4-mini
```

Голосовая модель: `OPENAI_MODEL_TRANSCRIBE=gpt-4o-mini-transcribe`. Реальный API проверен на синтетической русской записи: 7,47 секунды речи распознаны за 2,93 секунды. Физический микрофон пользователя во время проверки не записывался. Запись — первым нажатием, отправка — вторым; максимум 60 секунд. Голос заполняет черновик в чате; переход к нему — по уведомлению. Перед демонстрацией проверьте физический микрофон и разрешение браузера на своём устройстве.

Текстовые модели должны поддерживать Responses API, function calling, Structured Outputs и `reasoning.effort: none`. Для неизвестных тарифов стоимость показывается как неизвестная; стоимость аудио пока не вычисляется. NVIDIA в текущий MVP не подключена; GPU не используется.

Для запуска готовой сборки остановить dev-сервер (Ctrl+C), затем:

```sh
npm run build
npm start
```

Порт можно изменить: `npm run dev -- --port 3001`. Сервер слушает только `127.0.0.1`.

## Сценарий демонстрации (3–4 минуты)

Подробная таблица критериев — в [DEFINITION-OF-DONE.md](DEFINITION-OF-DONE.md).

1. **Массовая категория.** Кнопка «Ведущий на корпоратив» сразу запускает подбор на показанную дату 15 октября 2026. Для воспроизводимого сценария из отчёта открыть «Ручной режим»: Алматы, 15.10.2026, Ведущий, корпоратив, до 1 000 000 ₸, русский, 6 ч, пожелания «Интеллигентная, ненавязчивая подача и живой юмор». Подтвердить. Ожидаются Мицури Канроджи (`HK-44923`), Буллма (`HK-44733`), Хаул (`HK-77838`). Открыть «Почему подходит и анкета».
2. **Календарь и занятость.** В ручном режиме изменить дату на 17.10.2026 или открыть календарь по кнопке «цены»; нажать «Найти до 3 вариантов». Мицури занят и исключён; первые три: Буллма, Хаул, Кики (`HK-35215`). Причина исключения показана явно. Повтор неизменного запроса сохраняет порядок. Цены в календаре — минимальные начальные цены доступных анкет, не скидки.
3. **Редкая категория.** «Новый подбор» → «Флорист на корпоратив» сразу покажет карточку в чате. Для точного сценария из отчёта открыть «Ручной режим» и задать Алматы, Флорист, корпоратив, 15 октября, бюджет 400 000 ₸, без ограничений языка и часов, пожелания «Авторское цветочное оформление»; нажать «Найти до 3 вариантов». Одна анкета: Тони Тони Чоппер (`HK-39372`). Интерфейс показывает реальное количество результатов.
4. **Пустая выдача.** Готовый запрос «Ведущий до 100 тыс. ₸» запускается сразу на показанную дату. Для точного повтора отчёта задать все условия шага 1, уменьшить бюджет до 100 000 ₸ и подтвердить. Совпадений нет. Альтернатива 650 000 ₸ даёт одну анкету при остальных прежних условиях; нажатие «Применить и подобрать заново» явно запускает поиск.
5. **Нет категории.** В «Ручном режиме» задать условия флористики из шага 3, изменить город на «Зарубежье» и нажать «Найти до 3 вариантов». Получится отдельное состояние отсутствия категории.
6. **Избранное.** Нажать сердечко на карточке, перезагрузить страницу и открыть «Избранное». Анкета и условия сохранённого запроса остаются; это отметка в браузере, не бронь.
7. **Агент и экономика — со своим ключом.** Ввести: «Нужен ведущий в Алматы на корпоратив 15 октября, бюджет миллион тенге, русский язык, 6 часов. Спокойно, интеллигентно, с юмором». Проверить заполненную заявку, подтвердить подбор и открыть «Модели и расход API»: заполнение черновика → фильтры → объяснения с проверенными цитатами. Повтор неизменного запроса использует кеш.
8. **Голос — после проверки микрофона.** Микрофон находится в чате рядом с отправкой; плавающая кнопка удалена. Первое нажатие кнопки записи включает микрофон, второе завершает и отправляет аудио. Есть отмена и лимит 60 секунд. После расшифровки проверить черновик и отдельно подтвердить поиск. После подтверждения карточки появляются в ответе чата. Поисковые ответы сохраняют свои даты и не подменяются следующим подбором.
9. **Неполная заявка.** Описать запрос без даты: агент оставит её пустой и покажет календарь. Выбор даты ещё не запускает поиск; подтвердить отдельным нажатием.

## Чат и ручной режим

В чате каждый ответ содержит не более трёх карточек, сердечки и открытие полной анкеты. Текст — «Найдено 3 варианта» / «Найден 1 вариант»; после выполненного поиска блок подтверждения скрывается до изменения заявки.

В ручном режиме пользователь выбирает фильтры; окно остаётся открытым, результаты появляются ниже формы. Черновик и результаты ручного режима независимы от чата. Оба режима используют один движок и AI-объяснения при включённой опции. Избранное общее, хранится в браузере и открывается по кнопке в шапке.

При первом открытии ручная форма копирует текущую заявку чата, при повторном — сохраняет свои фильтры. «Новый подбор» очищает только чат; для очистки ручной формы есть «Сбросить». Поэтому после выбора другого примера в чате условия в уже открывавшемся ручном режиме нужно задать явно. «Повторить подбор на эту дату» из избранного отправляет новый результат в чат.

## Ограничения и честное описание AI

- Это подбор по учебному каталогу, без бронирования и подтверждения реальной доступности.
- Даты доступны только с 23.09 по 31.12.2026; цены начальные. Все метки происхождения сохранены.
- Ранжирование детерминированное, на основе явных лексических признаков стиля и запаса бюджета; эмбеддинги и дообучение не используются.
- Модель выбирает индивидуальные основания и точную цитату. Текст собирается из проверенных фактов; свободную генерацию неподтверждённых сведений не показываем. Недействительная цитата заменяется локальным объяснением.
- До трёх кандидатов передаются объясняющей модели; весь каталог и календарь не отправляются.
- При неработающем API форма и поиск продолжают работать. Ошибка разбора свободного текста явно сообщается, параметры молча не подменяются.
- Кеш — в памяти одного процесса, 30 минут, до 150 ответов. После перезапуска исчезает. Расход в панели относится к текущей вкладке, не ко всему аккаунту.
- Лимит: 30 запросов в минуту на локальный процесс. Нет регистрации, БД и обязательных внешних сервисов для поиска по форме.
- Избранное хранится только в этом браузере. Доступность карточки относится к сохранённой дате; для актуального подбора выполните поиск повторно.
- Аудио отправляется в OpenAI; приложение не сохраняет его на диск и не кеширует. Максимум — 8 МБ; стоимость аудио пока неизвестна.
- Иллюстрации созданы AI и не являются фотографиями подрядчиков, портфолио или основанием ранжирования. Источник: [VISUALS.md](VISUALS.md).
