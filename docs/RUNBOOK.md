# Запуск и демонстрация LPV Match

Проверено 23.09.2026: `npm test` — 16 тестов, `npm run build` — успешная production-сборка. Реальный запрос из браузера через nano + mini занял 4,18 с; оценочная стоимость $0,00165. Это отдельное измерение, а не гарантия скорости или стоимости каждого запроса.

## Быстрый запуск

Требуется Node.js 22+ и npm. Разработка проверена на Node.js 26.7.0.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

Открыть http://127.0.0.1:3000. Ключ не обязателен для формы, строгого поиска и локальных объяснений. Для разбора свободного текста и AI-выбора цитат добавьте **свой** `OPENAI_API_KEY` в `.env.local`. Ключ команды не поставляется и не нужен для независимого запуска локального режима.

Две модели настраиваются в `.env.local`:

```dotenv
OPENAI_MODEL_FAST=gpt-5.4-nano
OPENAI_MODEL_REASONING=gpt-5.4-mini
```

Модели должны поддерживать Responses API, function calling, Structured Outputs и `reasoning.effort: none`. Для неизвестных тарифов стоимость показывается как неизвестная. NVIDIA в текущий MVP не подключена; GPU не используется.

Для запуска готовой сборки остановить dev-сервер (Ctrl+C), затем:

```sh
npm run build
npm start
```

Порт можно изменить: `npm run dev -- --port 3001`. Сервер слушает только `127.0.0.1`.

## Проверки

```sh
npm test
npm run typecheck
npm run format:check
npm run build
```

Тесты не требуют ключа и не обращаются к внешнему API: интеграционные отказы/ответы провайдера имитируются. Проверяются все ограничения, границы бюджета/часов, 6600 запросов по официальному календарю, повторяемость порядка, альтернативы, несуществующие AI-цитаты, кеш и отказ API. Реальные API-вызовы дополнительно проверены вручную.

Повторный импорт исходника: `npm run data:import`. JSON уже включён в репозиторий, импорт для запуска не требуется.

## Сценарий демонстрации (3–4 минуты)

1. **Массовая категория.** Нажать «Ведущий на корпоратив». Алматы, 15.10.2026, корпоратив, до 1 000 000 ₸, русский, 6 ч, интеллигентная подача. Ожидаются Мицури Канроджи (`HK-44923`), Буллма (`HK-44733`), Хаул (`HK-77838`) в таком порядке. Раскрыть основания одной анкеты.
2. **Занятость.** Поменять дату на 17.10.2026. Мицури занят и исчезает; первые три: Буллма, Хаул, Кики (`HK-35215`). Повторить запрос — порядок тот же.
3. **Редкая категория.** Нажать «Камерная флористика». Одна анкета: Тони Тони Чоппер (`HK-39372`). Интерфейс объясняет, почему кандидатов меньше трёх.
4. **Пустая выдача.** Нажать «Проверить ограничения». Бюджет 100 000 ₸ не проходит. Есть проверенная альтернатива: 650 000 ₸, при остальных прежних условиях подходит одна анкета. Применение только по нажатию.
5. **Нет категории.** Для флористики выбрать «Зарубежье». Это отдельное состояние: в этой географии такой категории нет.
6. **Агент и экономика.** Ввести: «Нужен ведущий в Алматы на корпоратив 15 октября, бюджет миллион тенге, русский язык, 6 часов. Спокойно, интеллигентно, с юмором». Открыть «Как это работает»: nano → инструмент поиска → проверка ограничений → mini → проверенные цитаты. Видны реальные токены, время и оценка стоимости. Повтор через форму использует кеш объяснений.

## Ограничения и честное описание AI

- Это подбор по учебному каталогу, без бронирования и подтверждения реальной доступности.
- Даты доступны только с 23.09 по 31.12.2026; цены начальные. Все метки происхождения сохранены.
- Ранжирование детерминированное, на основе явных лексических признаков стиля и запаса бюджета; эмбеддинги и дообучение не используются.
- Модель выбирает индивидуальные основания и точную цитату. Текст собирается из проверенных фактов; свободную генерацию неподтверждённых сведений не показываем. Недействительная цитата заменяется локальным объяснением.
- До трёх кандидатов передаются объясняющей модели; весь каталог и календарь не отправляются.
- При неработающем API форма и поиск продолжают работать. Ошибка разбора свободного текста явно сообщается, параметры молча не подменяются.
- Кеш — в памяти одного процесса, 30 минут, до 150 ответов. После перезапуска исчезает. Расход в панели относится к текущей вкладке, не ко всему аккаунту.
- Лимит: 30 запросов в минуту на локальный процесс. Нет регистрации, БД и обязательных внешних сервисов для поиска по форме.
